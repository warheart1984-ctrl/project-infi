## 1. Mission

To define the identity, scope, terminology, relationships, and architectural purpose of the Constitutional Cyber & AI Learning Framework (CCALF).

CCALF establishes a governed learning architecture for cybersecurity, AI engineering, governance, and technical stewardship.

## 2. Scope

CCALF applies to:

- Individual learners
- Educational programs
- Organizations
- Governance bodies
- Domain specifications
- Evidence repositories
- Conformance processes

CCALF governs how knowledge is structured, validated, versioned, and stewarded.

## 3. Architectural Identity

CCALF is a constitutional learning system, not a curriculum.

It defines:

- How knowledge is organized
- How competency is demonstrated
- How evidence is verified
- How domains evolve
- How stewardship is maintained

CCALF is modular, governed, and interoperable.

## 4. Specification Family

The CCALF specification family consists of:

- CCALF-000 — Framework Overview
- CCALF-050 — Constitutional Principles
- CCALF-100 — Curriculum Architecture
- CCALF-200 — Governance Specification
- CCALF-300 — Evidence Specification
- CCALF-400 — Conformance Specification
- CCALF-500 Series — Domain Specifications
- CCALF-510 — Domain Template Specification

Each specification is independent and versioned.

## 5. Terminology

| Term | Definition |
|------|------------|
| Learner | An individual participating in CCALF. |
| Domain | A governed area of knowledge. |
| Evidence | Verifiable artifacts demonstrating competency. |
| Maturity Level | A competency tier (L0–L5). |
| Steward | A practitioner at maturity level L5. |
| Governance Body | Entity responsible for review and versioning. |

## 6. Relationships

- Principles govern all specifications.
- Curriculum defines learning architecture.
- Evidence validates learning outcomes.
- Conformance certifies competency.
- Governance manages evolution.
- Domains instantiate the architecture.

## 7. Intended Audience

- Learners
- Educators
- Organizations
- Governance bodies
- Standards groups
- Technical leaders
