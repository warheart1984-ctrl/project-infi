## 1. Purpose

To define what it means for learners, curricula, and organizations to be CCALF-conformant.

## 2. Conformance Classes

### 400.1 Learner Conformance

A learner is CCALF-conformant when:

- Evidence satisfies maturity criteria
- Evidence is verified
- Stewardship is demonstrated
- Constitutional principles are upheld

### 400.2 Curriculum Conformance

A curriculum is CCALF-conformant when:

- It implements all learning layers
- It maps activities to the lifecycle
- It defines maturity criteria
- It produces valid evidence

### 400.3 Organizational Conformance

An organization is CCALF-conformant when:

- It adopts CCALF governance
- It maintains evidence repositories
- It supports review cycles
- It enforces stewardship

## 3. Conformance Process

Conformance requires:

- Evidence submission
- Review
- Verification
- Maturity assignment
- Governance approval

## 4. Renewal

Conformance must be renewed periodically through updated evidence and stewardship review.
