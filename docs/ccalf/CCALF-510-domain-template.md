> **Honesty tag:** These documents are **declared/adopted framework specs**. They do not claim runtime enforcement inside host product engines unless a separate implementation and tests prove otherwise.

## 1. Purpose

To define the reusable template for all CCALF 500-series domain specifications.

## 2. Template Structure

### 510.1 Domain Mission

Statement of purpose and scope.

### 510.2 Domain Layers

Mapping of domain content to the five learning layers.

### 510.3 Domain Lifecycle Mapping

Definition of domain-specific activities for each lifecycle phase.

### 510.4 Domain Evidence Requirements

Required evidence types for each layer and maturity level.

### 510.5 Domain Maturity Criteria

Definition of L0–L5 criteria specific to the domain.

### 510.6 Domain Standards

List of relevant industry, regulatory, and constitutional standards.

### 510.7 Domain Reference Architectures

Canonical models, diagrams, and structures.

### 510.8 Domain Governance Rules

How the domain interacts with CCALF governance.

### 510.9 Domain Stewardship Requirements

Criteria for L5 stewardship within the domain.

## 3. Template Invariants

All domain specifications must:

- Uphold CCALF-050
- Implement CCALF-100
- Produce CCALF-300 evidence
- Support CCALF-400 conformance
- Maintain interoperability with other domains
