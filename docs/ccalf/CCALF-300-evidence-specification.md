## 1. Purpose

To define the types, structure, lineage, and verification requirements for competency evidence.

## 2. Evidence Types

Domains may use any of the following evidence types:

- Reading notes
- Standards mapping
- Labs
- Projects
- Architecture documents
- Documentation
- Reflections
- Portfolio artifacts
- Stewardship records

## 3. Evidence Requirements

### 300.1 Lineage

Each artifact must include origin, date, domain, layer, and maturity mapping.

### 300.2 Verification

Evidence must be reviewable and reproducible by independent reviewers.

### 300.3 Versioning

Evidence must be versioned and linked to the learner's constitutional record.

### 300.4 Mapping

Each artifact must map to:

- A learning layer
- A maturity level
- A domain requirement
- A conformance criterion

### 300.5 Integrity

Evidence must be authentic, attributable, and free of fabrication.

## 4. Evidence Ledger

The learner's constitutional record stores:

- Evidence lineage
- Review history
- Maturity progression
- Governance interactions
