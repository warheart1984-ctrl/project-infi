# CCALF v1.0 — Unified Specification Bundle

**Status:** Adopted as declared framework documentation (foundational / operational / domain as labeled).  
**Not:** a runtime engine gate in host repositories (Drive-G-1 evidence-bound wording).

## Mission (summary)

The Constitutional Cyber & AI Learning Framework (CCALF) establishes a governed learning architecture for cybersecurity, AI engineering, governance, and technical stewardship.

## Relationship to host governance

- **CCALF** governs learning, competency stewardship, evidence, and domain curriculum architecture.
- Host product charters / agent lawbooks (for example MRS `AGENTS.md` and 4DCE/4DRS) remain binding for agents and runtime in those repos.
- CCALF-050 must **not** silently rewrite product constitutional charters; conflicts are documented, not merged.
